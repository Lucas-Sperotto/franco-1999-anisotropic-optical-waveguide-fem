# Patch Codex T-001

## 1. Tarefa implementada

T-001 — Criar comando reprodutível de testes.

O objetivo foi evitar o `ctest` encontrado primeiro no `PATH` (`/home/sperotto/.local/bin/ctest`), que falha por depender do módulo Python `cmake`, e expor um comando local estável para a suíte.

## 2. Arquivos modificados

- `scripts/test.sh`
- `README.md`
- `tests/README.md`
- `TODO.md`

## 3. Decisões técnicas

- O novo `scripts/test.sh` chama `/usr/bin/ctest --test-dir build --output-on-failure` diretamente.
- O script aceita `BUILD_DIR` para trocar o diretório de build e `CTEST_BIN` para trocar o binário de CTest, mantendo `/usr/bin/ctest` como padrão.
- A documentação foi atualizada apenas no ponto necessário para registrar o comando de teste reprodutível.
- A T-001 foi marcada como concluída em `TODO.md` depois da verificação bem-sucedida.

## 4. Comandos executados

```bash
cmake -S . -B build
cmake --build build -j
ctest --test-dir build --output-on-failure
./scripts/test.sh
```

## 5. Resultados

- `cmake -S . -B build`: passou.
- `cmake --build build -j`: passou.

